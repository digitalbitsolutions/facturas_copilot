# Trabajo con Codex

Al iniciar una sesión, leer `README.md`, `CONTEXT.md`, el área relevante de `TODO.md`, `git status --short` y los commits recientes. Cargar solo los archivos necesarios para la tarea.

Ejecutar directamente el trabajo determinista y utilizar Codex para el desarrollo, revisión y generación de código. Validar siempre los cambios con herramientas deterministas apropiadas, como pruebas, tipos, compilación o formato.
